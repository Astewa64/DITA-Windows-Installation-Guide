# DITA Windows Installation Guide

## Alim Stewart | Technical Documentation Portfolio

### About This Project

I created this project as part of my professional development in technical content and documentation. The project demonstrates my hands on practice with DITA XML, structured authoring, technical writing, and user focused documentation.

The guide provides beginner friendly instructions for installing software on Windows and separates the information into structured DITA topics, allowing each topic to serve a specific purpose within the documentation set.

### Project Structure

- **overview.dita**: Introduces the software installation guide and provides important background information.
- **installation.dita**: Uses a DITA task structure to provide prerequisites and step-by-step installation instructions.
- **troubleshooting.dita**: Provides troubleshooting guidance for common software installation problems.
- **windows-installation.ditamap**: Organizes and connects the individual DITA topics into a complete documentation set.
